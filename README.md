# AI Resume Analyzer

An AI-inspired Resume Analyzer built using Python and Flask that evaluates resumes, 
extracts skills, calculates ATS scores, recommends job roles, and provides personalized feedback.

## Features
- Resume PDF Upload
- Skill Extraction
- ATS Score Calculation
- Job Recommendations
- Resume Feedback
- Web-Based Dashboard

## Tech Stack
- Python
- Flask
- PDFPlumber
- HTML
- CSS

## Installation

git clone <repository-link>

pip install -r requirements.txt

python app.py
